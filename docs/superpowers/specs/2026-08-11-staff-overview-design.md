# 직원 현황판 (한눈에 보기) 설계 (2026-08-11)

## 배경
사장님이 직원 업무를 보려면 헤더 드롭다운에서 이름을 하나씩 골라야 한다.
5명 상황을 파악하려면 5번 클릭해야 하고, 누가 아직 안 썼는지 한눈에 안 보인다.

## 목표
선택한 기간(오늘/내일/주간/월간/연간)의 **활성 직원 전원 업무를 한 화면에** 읽기 전용으로 보여준다.

## 비목표 (YAGNI)
- 현황판에서의 직접 수정 (읽기 전용 — 수정은 기존 개인 화면)
- 기간 합산 통계, 기록 추이, 내보내기

## API
`GET /api/report/overview?period=<기간>&date=<YYYY-MM-DD>` (사장님 전용)

응답:
```json
[{ "staff_id": 1, "name": "미가", "items": [{ "id":1, "title":"...", "memo":"...", "done":0 }] }]
```
- `role='staff' AND is_active=1` 전원 포함 — **항목이 0건인 직원도 빈 배열로 포함**(누가 안 썼는지가 핵심 정보)
- 사장님 행(`role='boss'`)은 제외
- 직원 세션은 403, 잘못된 `period`는 400
- 쿼리 2번(직원 목록 1 + 항목 1)으로 처리 — 직원 수만큼 요청하지 않는다

## 화면
드롭다운 맨 위 `👥 직원 현황`(value=`all`), 사장님 로그인 시 기본 선택.
순서: 직원 현황 → 🏠 내 업무 → 직원 이름들.

카드 1장 = 직원 1명:
- 헤더: 이름 + `3/5 완료` + 진행 막대
- 오늘/내일: 항목 목록. 완료는 회색 취소선, 미완료는 검정. 메모는 옆에 작게
- 주간/월간/연간: 그 사람이 쓴 자유메모 본문을 그대로 표시
- 항목 0건이면 회색 `아직 작성 없음`

읽기 전용 — 체크박스·입력창 없음. 수정하려면 드롭다운에서 그 직원을 선택한다.

## 테스트
1. 활성 직원 전원 반환, 항목 0건 직원도 포함
2. 사장님 행 미포함
3. 항목이 사람별로 정확히 묶임
4. 직원 세션 403
5. 잘못된 period 400
