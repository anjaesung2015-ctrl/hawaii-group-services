# 엘리트선수반 선수 등록 방법

사장님·선수반 코치용 안내. 앱: https://app.hawaiigroup.co/booking/

## 1. 선수 등록하기 (사장님·선수반 코치)

1. 하단 **Elite** 탭 → 위쪽 **Players** → **+ Add player**를 누릅니다.
2. 아래 칸을 채웁니다.

| 칸 | 넣는 것 |
|---|---|
| **Name** | 선수 이름 (필수) |
| **Phone** | 로그인 번호 8자리 (필수). 주니어는 **부모 번호** |
| **PIN** | 4자리. 비우면 **번호 뒤 4자리** |
| Birth year | 출생연도 |
| Level | New / Beginner / Intermediate / Advanced |
| Coach | 담당 코치 |
| Parent name / Parent phone | 부모 이름·연락처 |
| **Monthly tuition** | 그 선수의 월 수강료. **비우면 기본 800,000₮** |
| Note | 메모 |

3. **Save**를 누르면 화면에 첫 PIN이 뜹니다. 이 번호를 선수나 부모에게 알려 주세요.

## 1-1. 신청 링크로 받기 (승인은 사장님만)

직접 등록하는 대신, 선수나 부모가 스스로 신청하게 할 수도 있습니다. 아래 링크를 보내면 엘리트선수반 신청서가 바로 열립니다.

> https://app.hawaiigroup.co/booking/#join-elite

1. 선수(부모)가 이름·전화번호·PIN·출생연도·부모 연락처를 적고 개인정보 동의 후 신청합니다. 입회비는 없고 월 수강료 안내만 나옵니다.
2. 사장님 폰으로 알림이 갑니다. **Elite → Players** 맨 위 신청 목록에서 **Approve**를 누르면 바로 선수 계정이 됩니다.
3. 선수는 신청할 때 정한 번호와 PIN으로 로그인합니다.

선수반 코치에게는 신청 목록이 보이지 않습니다. 신청했다는 연락을 받으면 사장님께 승인을 요청해 주세요.

## 2. 선수(부모)에게 보낼 안내

> 앱 주소: https://app.hawaiigroup.co/booking/
> 로그인: 전화번호 ○○○○○○○○ / PIN ○○○○
> 로그인 후 ☰ 메뉴 → **Notifications**를 켜 주세요 (훈련·공지·수강료 알림)
> ☰ 메뉴 → **Change PIN**에서 PIN을 바꿀 수 있어요

선수가 로그인하면 **Training**(훈련 일정·내 출석), **Fees**(내 수강료·계좌), **Notices**(선수반 공지) 세 탭만 보입니다.

## 3. 등록한 뒤에 할 일

- **이번 달 수강료를 이미 받았다면:** Elite → **Fees**에서 그 선수의 ✓를 눌러 체크합니다. 체크하지 않으면 매월 20일 이후(오전 10시~밤 9시) 미납 알림이 갑니다. 20일이 지난 뒤 등록한 선수도 알림을 켜면 그 달 알림을 한 번 받습니다.
- **사진:** 선수 줄을 눌러 수정 화면 → 📷 사진 선택.
- **PIN을 잊었을 때:** 선수 줄을 누르고 → **Reset PIN**.
- **그만둔 선수:** 수정 화면에서 상태(Status)를 **Left(휴면)**로 바꿉니다. 바로 로그인이 막히고, 출석·수강료 기록은 남습니다. 삭제하면 기록까지 모두 지워집니다.

## 4. 선수반 코치 지정하기 (사장님만)

Elite → Players 아래 **+ Add elite coach**에서 동호인 회원 중 한 명을 고릅니다. 지정된 코치에게는 Elite 탭이 생겨 선수·일정·출석·수강료·공지를 관리할 수 있습니다. 해제는 같은 곳에서 **Remove**를 누르면 됩니다.

동호인 임원(회장·총무 등)은 선수반 코치로 지정하지 않으면 선수반을 볼 수 없습니다.

## 주의

- **번호 하나에 계정 하나입니다.** 형제를 같은 부모 번호로 둘 다 등록할 수는 없으니, 다른 번호(엄마/아빠 번호 등)를 쓰세요.
- 동호인 회원으로 이미 등록된 번호는 선수로 등록할 수 없습니다.
- 선수 계정으로는 동호인 화면(일정·게시판·채팅·회비·공지·명단)을 볼 수 없고, 동호인 회원은 선수반을 볼 수 없습니다.
