# 🎾 Hawaii Tennis Club — 회원 전용 웹앱

몽골 울란바토르 동호인 테니스 클럽을 위한 폰 우선(mobile-first) 웹앱입니다.
일정·회비·공지·회원 명단을 한 곳에서 관리하고, 회원은 폰 홈 화면에 앱처럼 추가해 씁니다.

**실제 주소: https://app.hawaiigroup.co/booking/**

- 서버: Node.js + Express
- 데이터: SQLite 파일 하나 (`data/club.db`)
- 화면: 순수 HTML / CSS / JavaScript (프레임워크 없음)
- 언어: 몽골어(기본) / 한국어 — 화면 오른쪽 위 버튼으로 전환
- PWA: 홈 화면에 추가하면 주소창 없이 독립 앱처럼 열립니다

## 1. 준비 — Node.js

사장님 PC에는 이미 설치돼 있습니다 (**Node v24.14.1 / npm 11.11.0**). 확인만 하려면:

```bash
node -v
npm -v
```

버전이 안 나오면 아래처럼 설치합니다. **Node.js 18 이상**이면 됩니다.

### Windows
1. https://nodejs.org 에서 **LTS** 버전을 내려받습니다 (`.msi`).
2. 설치 파일을 실행하고 기본값으로 **다음 → 다음 → 설치**를 누릅니다.
3. 설치가 끝나면 **새 터미널**(PowerShell 또는 명령 프롬프트)을 열고 `node -v` 로 확인합니다.

또는 터미널에서 한 줄로:

```powershell
winget install OpenJS.NodeJS.LTS
```

### macOS
```bash
brew install node
```

### Ubuntu / Debian 서버
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
```

> ⚠ `better-sqlite3` 는 **13 버전 이상**을 써야 합니다. 11 버전은 Node 22/24용 미리 빌드된 파일이 없어
> 설치할 때 직접 컴파일을 시도하다 실패합니다(윈도우에 빌드 도구가 없으면 반드시 깨집니다).

## 2. 내 PC에서 실행 (개발·연습용)

```bash
cd hawaii-tennis-club

npm install        # 1) 필요한 꾸러미 설치 (처음 한 번)
npm run seed       # 2) 테스트용 샘플 데이터 넣기 (선택)
npm start          # 3) 서버 실행
```

실행되면 터미널에 이렇게 나옵니다.

```
  🎾 Hawaii Tennis Club
  ➜  http://localhost:3000
     월회비 200,000₮ · 입회비 300,000₮
```

브라우저에서 **http://localhost:3000** 을 엽니다. 끄려면 터미널에서 `Ctrl + C`.

> 실제 클럽 회원이 쓰는 건 EC2에 올라간 쪽입니다(**5번** 참고). 내 PC에서 띄우는 건 연습·시험용이고
> 데이터도 따로입니다.

## 3. 로그인

### EC2(실제 운영)

| 구분 | 전화번호 | PIN |
|---|---|---|
| 관리자 (안재성 · 대표) | `88012222` | `2905` |

**나머지 회원은 직접 가입 신청합니다.** 로그인 화면의 **가입 신청** 버튼 →
이름·전화번호·PIN(4자리)·레벨을 적어 신청 → 대표가 승인하면 그 PIN으로 바로 로그인됩니다.

- 신청만으로는 아무것도 볼 수 없습니다 (승인 전 로그인 불가)
- 승인은 **회원 탭 맨 위 `가입 신청` 칸**에서 `승인` / `거절`. 홈 화면에도 신청 건수가 뜹니다
- 승인하면 그 사람의 **입회비 미납 한 줄**이 자동으로 섭니다
- 같은 번호로 두 번 신청할 수 없고, 이미 회원인 번호도 막힙니다
- 한 아이피에서 한 시간에 5건까지만 신청됩니다 (장난 신청 방지)
- 거절당한 사람은 다시 신청할 수 있습니다

### 샘플 없이 처음 실행했다면

서버를 처음 켤 때 **관리자(대표) 계정이 자동으로 하나 만들어지고**, 터미널에 번호와 PIN이 찍힙니다.

```
  ───────── 첫 관리자 계정을 만들었습니다 ─────────
   이름     : 대표
   전화번호 : 99000000
   PIN      : 1234
   ⚠  로그인한 뒤 바로 PIN을 바꿔주세요
```

번호·PIN을 직접 정하고 싶으면 처음 실행할 때만 이렇게 합니다.

```bash
# Windows PowerShell
$env:ADMIN_NAME="안재성"; $env:ADMIN_PHONE="99887766"; $env:ADMIN_PIN="2580"; npm start

# macOS / Linux
ADMIN_NAME=안재성 ADMIN_PHONE=99887766 ADMIN_PIN=2580 npm start
```

## 4. 기능

### 권한 2개

| | 관리자 (대표·코치) | 일반회원 |
|---|---|---|
| 가입 | 신청 승인·거절 | (회원이 되기 전 신청) |
| 일정 | 등록·수정·삭제 | 참석/불참/미정 응답 |
| 회비 | 전체 현황표, 완납 체크 | 본인 내역만 조회 |
| 공지 | 작성·수정·삭제·고정 | 읽기 |
| 회원 | 추가·수정·삭제·PIN 재설정 | 이름·레벨만 조회 |
| 설정 | 회비 금액·클럽 이름 변경 | — |

### 홈
다가오는 일정 3개(바로 참석 응답 가능), 고정 공지, 그리고 관리자에게는 **이번 달 미납자**,
회원에게는 **내 미납 회비**가 보입니다.

### 일정
- 제목 / 종류(**정기모임·행사·대회**) / 날짜 / 시작·종료 시간 / **코트 수** / 메모
- 회원은 **참석·미정·불참** 중 하나를 고릅니다 (언제든 바꿀 수 있고, 한 사람이 중복으로 세어지지 않습니다)
- 일정을 누르면 **참석 인원과 명단**이 펼쳐집니다
- `다가오는` / `지난` 탭으로 나뉩니다
- **반복 등록**: 일정 등록 창에서 `반복 등록` 을 켜고 요일(화·목 등)과 기간을 고르면 그 사이 날짜가 한 번에 등록됩니다.
  몇 개가 만들어질지 미리 보여주고, 같은 제목·날짜·시간이 이미 있으면 건너뜁니다(두 번 눌러도 안 겹칩니다).
  한 번에 120개까지 — 실수로 몇 년치를 만드는 것을 막습니다
- **제목에서 요일 알아보기**: 제목에 `수요일모임` 이라고 적으면 반복이 켜지고 수요일이 자동으로 선택됩니다.
  `화목 정기모임`·`월수금 레슨`·`매주 토`·`주말`·`평일`, 몽골어 `Лхагва гарагт`·`Хагас сайн` 도 알아봅니다.
  기간은 그날부터 6주로 채워지고, 요일을 직접 누르기 시작하면 더 이상 제목을 따라가지 않습니다.
  `11월`·`목표`·`화목한`·`수고` 처럼 요일이 아닌 말은 걸러냅니다(`test/weekdays.test.js`)

### 회비
- 기본 **월회비 200,000₮ · 입회비 300,000₮** — ☰ → 설정에서 변경
  (이미 기록된 납부 줄의 금액은 바뀌지 않습니다)
- 관리자: 월별 현황표에서 **✓ 한 번에 완납 처리** → 납부일과 방법(**현금·계좌이체·QPay**)을 기록합니다.
  잘못 눌렀으면 미납으로 되돌릴 수 있습니다
- `‹ 10월 ›` 로 지난 달을 넘겨볼 수 있고, 아래에 **미납자 목록**이 따로 모입니다
- 입회비 미납은 이름 아래 빨간 뱃지로 뜨고, 눌러서 바로 수납 처리합니다
- 회원: 본인 납부 내역만 봅니다 (남의 회비는 서버에서 막습니다)
- **휴면 회원에게는 월회비를 매기지 않습니다**

### 게시판 (자유게시판)
- **회원 누구나** 글을 쓰고 **사진 최대 4장**을 붙입니다 (폰 사진은 자동으로 줄여 올립니다)
- 댓글과 좋아요(♡). 최신 글부터 20개씩, `더 보기` 로 이어 봅니다
- 내 글은 내가 고치고 지웁니다. **관리자는 아무 글·댓글이나 지울 수 있습니다**(클럽 운영상)
- 사진을 누르면 크게 보이고, 사진은 **로그인한 회원만** 열 수 있습니다
- 공지와 다른 점: 공지는 관리자만 쓰는 전달용, 게시판은 회원끼리 쓰는 곳입니다

### 폰 알림 (웹 푸시)

☰ → **폰 알림** → `알림 켜기` 를 누르면 그 폰으로 알림이 옵니다. 텔레그램 봇도, 돈도 들지 않습니다.

| 언제 | 누구에게 |
|---|---|
| 새 공지 | 쓴 사람 빼고 전원 |
| 게시판 새 글 | 쓴 사람 빼고 전원 |
| 내 글에 댓글 | 글쓴이에게만 |
| 새 일정 (반복 등록은 한 번만) | 등록한 사람 빼고 전원 |
| 가입 신청 | 관리자에게만 |
| **일정 하루 전 저녁 6시** | 전원 (자동) |
| **매월 10일 아침 10시** | 그 달 회비 미납자에게만 (자동) |

- 한 사람이 **여러 기기**(폰·PC)를 켤 수 있고, 기기마다 따로 끕니다
- 휴면 회원에게는 보내지 않습니다. 앱을 지운 폰(만료 구독)은 자동으로 정리됩니다
- 알림이 실패해도 글·공지·일정은 그대로 저장됩니다 (알림은 덤)
- 같은 알림을 두 번 보내지 않습니다 — 일정은 `event.reminded_at`, 회비는 설정값 `due_reminder_month` 로 표시를 남깁니다
- **아이폰은 홈 화면에 추가해야** 알림이 옵니다(iOS 제약). 앱이 감지해 안내를 띄웁니다
- 알림 키(VAPID)는 `data/vapid.json` 에 자동 생성됩니다 — **이 파일을 지우면 모든 구독이 끊깁니다**(백업 대상)

### 회칙

☰ → **클럽 회칙**. 한국어·몽골어 두 가지로 들어 있고 화면 언어에 따라 보입니다.

- **로그인 없이도 읽힙니다** — 가입하려는 사람이 먼저 읽어야 하니까요
- **가입 신청 때 동의 체크가 필수**입니다(제6조7 서명 대신). 동의한 시각과 판 번호가 신청에 남고, 승인하면 회원 기록으로 넘어갑니다
- 아직 동의하지 않은 회원은 로그인 직후 회칙이 한 번 떠서 동의를 받습니다
- 관리자는 **☰ → 회칙 → 회칙 수정** 으로 고칩니다. 저장하면 판 번호가 1 올라가고 **회원들에게 다시 동의를 받습니다**(부칙 제2조)
- 원문은 `lib/rules-text.js`(처음 내용) → DB `doc` 테이블에 들어갑니다. 앱에서 고친 내용을 코드가 덮어쓰지 않습니다

> 2026-10-16 사장님 지시로 두 가지를 바꿨습니다: **추천을 받으면 게스트 2회**(추천 없이 신청하면 4회),
> **휴회 제도 삭제**(옛 제9조). 조문 번호를 당기고 상호 참조(제12조·제25조·제31조)까지 맞췄습니다.
> 앱의 회원 상태 `휴면` 은 **`탈퇴`** 로 이름을 바꿨습니다 — 지우면 회비 이력이 사라지므로 기록 보존용으로 남깁니다.

- 회원을 추가하면 **입회비 미납 한 줄**이 자동으로 섭니다

## 5. EC2 배포 (실제 운영 중)

**https://app.hawaiigroup.co/booking/**

> 2026-10-15: 원래 이 주소는 **코트예약(court-booking)** 이었습니다. 사장님 요청으로 코트예약을 내리고
> 이 자리를 하와이클럽이 물려받았습니다 — 회원들이 이미 아는 주소와 홈화면 아이콘을 그대로 쓰기 위해서입니다.
> 옛 `/club/` 주소로 들어와도 `/booking/` 으로 넘겨줍니다.

| 항목 | 값 |
|---|---|
| 위치 | EC2 `~/.openclaw/workspace/hawaii-tennis-club` |
| 포트 | 6032 (nginx `/booking/` → `127.0.0.1:6032`, 프리픽스 벗김) |
| 프로세스 | pm2 `hawaii-tennis-club` · `pm2 save` 완료 · 서버 재부팅 시 자동 실행 |
| 설정 | `ecosystem.config.cjs` — `PORT=6032`, `COOKIE_PATH=/booking`, `SECURE_COOKIE=1` |
| 세션 키 | `data/.secret` (자동 생성 · git 제외 · 지우면 전원 로그아웃) |
| 백업 | 매일 03:30 `backup.js` → `~/backups/hawaii-tennis-club/` (DB + 공지 사진, 30일 보관) |

서버에서 자주 쓰는 명령:

```bash
cd ~/.openclaw/workspace/hawaii-tennis-club
pm2 restart hawaii-tennis-club      # 코드 바꾼 뒤
pm2 logs hawaii-tennis-club --lines 50
node backup.js                      # 지금 바로 백업
```

> **하위 경로(`/booking/`)에 올렸기 때문에 화면의 모든 경로는 상대 경로여야 합니다.**
> `/css/app.css` 처럼 앞에 `/` 를 붙이면 그 자원을 도메인 루트에서 찾다가 깨집니다.
> `test/i18n.test.js` 의 "화면 자원·API 경로가 모두 상대 경로다" 테스트가 이를 지킵니다.

## 6. 실제 운영 준비 (2026-10-15 완료)

- 샘플 데이터(가짜 회원 10명·일정·회비·공지)를 **모두 지웠습니다**
- 대표 계정만 남았습니다: **안재성 / `88012222` / PIN `2905`**
- 가입 안내 공지 1건을 몽골어·한국어로 올려 상단 고정했습니다
- 회원은 **가입 신청 → 대표 승인**으로 들어옵니다 (**3번** 참고)

회원을 직접 넣고 싶을 때는 **회원 탭 → + 회원 추가** 도 그대로 쓸 수 있습니다
(PIN을 비우면 전화번호 뒤 4자리가 첫 PIN).
회비 금액은 **☰ → 설정**에서 바꿉니다.

### 데이터 백업·복구

데이터는 **`data/club.db` 파일 하나**와 공지 사진 폴더 `uploads/` 에 전부 들어 있습니다.

```bash
node backup.js                                    # 지금 바로 백업
ls ~/backups/hawaii-tennis-club/                  # 백업 목록

# 복구 (서버를 끈 상태에서)
pm2 stop hawaii-tennis-club
cp ~/backups/hawaii-tennis-club/club-20261015-185703.db data/club.db
pm2 start hawaii-tennis-club
```

### PIN을 잊었을 때

- 회원 한 명: 관리자가 **회원 탭 → 그 회원 → PIN 재설정**
- 관리자 본인: 서버에서 아래 한 줄 (PIN을 `1234` 로 되돌림)

```bash
cd ~/.openclaw/workspace/hawaii-tennis-club
node -e "const{open,hashPin}=require('./lib/db');const db=open();db.prepare(\"UPDATE member SET pin_hash=? WHERE phone='88012222'\").run(hashPin('2905'));db.close();console.log('PIN 2905 로 되돌렸습니다')"
```

```bash
# Windows PowerShell

```
